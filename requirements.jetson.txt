# =============================================================================
# requirements.jetson.txt — extra Python packages for the Jetson Orin Nano image
#
# READ THIS FIRST:
# This file is ONLY used by Dockerfile.jetson. It is NOT the competition
# submission file. The submission file is requirements.txt, and that one targets
# a normal x86 + CUDA 12.8 machine.
#
# Some packages are deliberately MISSING from this list, on purpose:
#
#   torch, torchvision  ->  come from the L4T base image. On a Jetson these have
#                           to be the NVIDIA-built, GPU-enabled wheels; the ones
#                           on PyPI for ARM64 are CPU-only, so we must never let
#                           pip install them on top.
#
#   opencv-python       ->  also comes from the L4T base image, where it is built
#                           WITH GStreamer + CUDA so the NVDEC video decode works.
#                           The PyPI wheel has no GStreamer at all. If pip ever
#                           installs it (or opencv-python-headless) it overwrites
#                           the good OpenCV and silently kills hardware decoding,
#                           which is exactly why albumentations is left out below.
#
#   numpy, pillow       ->  left to whatever versions the base image's torch and
#                           OpenCV were built against, so we don't upgrade them
#                           out from under torch and break the ABI.
#
#   albumentations      ->  only used by src/utils/dataset.py (training/data prep),
#                           never on the inference path that the grader runs. It
#                           is dropped here because it drags in
#                           opencv-python-headless, which would clobber the
#                           base OpenCV described above.
#
# Everything below is pure-Python or has clean ARM64 wheels and is safe to add
# on top of the base image. Versions stay pinned to match requirements.txt.
# =============================================================================
